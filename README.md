# 우리봇v2

마인크래프트 커뮤니티 서버용 디스코드 봇과, 같은 데이터를 쓰는 웹 거래소 **우리거래소**.
가상 경제(돈·주식·코인·채굴·대출)를 중심으로 음악방송, AI 채팅, RPG, TRPG, 마인크래프트 서버 연동까지 한 봇에 들어 있다.

> 이 저장소에는 픽시브 검색 기능이 빠져 있다. `!픽시브` 명령은 없고, AI의 픽시브 툴은 "없는 기능"이라고만 답한다.

---

## 기능

### 💰 경제
| 명령 | 설명 |
|---|---|
| `!출석` | 하루 한 번 30,000원 |
| `!돈 [@유저]` · `!순위` | 순자산(현금 + 주식 + 코인 + 채굴기 + 레버리지 − 대출)과 재산 순위 |
| `!송금 [@유저] [금액]` | 돈 보내기 |
| `!대출 [금액]` · `!상환` · `!내대출` | 최대 1억, 10분마다 원금의 2% 이자, 10일 안에 못 갚으면 압류 |
| `!채굴` | 채굴기를 사서 10분마다 사토시를 번다. 가끔 정전 같은 사고가 난다 |
| `!복권` | 일요일 21시 추첨, 판매액의 90%를 한 명이 가져간다 |
| `!허세` · `!칭호` | 아무 효과 없는 물건과 칭호를 사서 돈을 날리는 곳. 허세 순위, 직접 짓는 칭호 |
| `!정보 [@유저]` | 다른 사람이 써 주는 소개글 (본인은 못 고친다) |

### 📈 주식 (`주식.py`)
실제 코스피·코스닥 3년치 통계(`시장자료.json`)로 움직이는 주가 엔진.

- **장 시간**: 매일 07:30 ~ 20:00, 5초마다 움직인다. 코인은 업비트 시세를 따라 24시간.
- **움직임**: 하루 등락 = 베타 × 지수 + 업종 민감도 × 업종 + 고유 움직임. 종목마다 같은 시장·업종의 실제 종목을 본떠서 성격이 정해진다. 어제 많이 움직였으면 오늘도 크게 움직이고(GARCH), 장 초반·막판에 출렁임이 크다.
- **업종 20개**: 반도체·전자·배터리·IT·게임·엔터·자동차·바이오·화학·광업·중공업·조선·건설·금융·식품·유통·수공업·운송·공공·종합.
- **실제 시장 규칙**: 상한가·하한가, 정적 VI(종목 2분 정지), 서킷브레이커(시장 전체 정지), 분기 실적 발표(어닝 서프라이즈·쇼크), 배당과 배당락, 거래량.
- **ETF 11개**: 코스피·코스닥 지수, 2배 레버리지, 인버스, 업종 ETF. 매일 리셋이라 레버리지·인버스는 음의 복리가 생긴다.
- **레버리지**: 2·3·4배 롱/인버스, 자동 충전, 강제 청산. 갭으로 0 밑까지 떨어지면 빚이 생긴다.
- **예약 주문**: 지정가 매수·매도, 손절.
- **세금**: 증권거래세 0.2%, 양도세 22%(250만 원 공제), 배당소득세 15.4%.
- **명령**: `!주식` · `!매수` · `!매도` · `!내주식` · `!주식 그래프 [종목] [기간]`(캔들 차트 PNG) · `!업종` · `!ETF` · `!레버리지` · `!주문` · `!배당` · `!실적` · `!세금` · `!주식추가`(유저도 돈 내고 상장 가능)

### 🎵 음악방송
유튜브에서 받아 음성채널에 트는 공용 방송.

- `!음악방송` · `!노래신청 [노래] [반복]` · `!노래리스트 [셔플/순서/빼기/비우기]` · `!현재노래` · `!스킵` · `!일시정지` · `!재개`
- `!플레이리스트` — 만들기, 유튜브 플레이리스트 가져오기, 반복·셔플 반복 재생
- 봇을 재시작해도 같은 채널, 같은 곡, 같은 위치에서 이어서 튼다.

### 🤖 AI 채팅
AI 채널에서 말을 걸면 Gemini가 대답한다. 함수 호출로 봇 기능을 직접 쓴다. 주가 조회, 매수·매도, 레버리지, 예약 주문, 노래 신청, 대기열 조작, 마크 서버 상태, 웹 검색 같은 것들이다.

- 유저마다 대화 기억(`!AI기억`, `!기억공개`)과 말투 프롬프트(`!AI프롬포트`)를 따로 둔다.

### ⚔️ RPG (`RPG.py`)
버튼으로 하는 무한 던전 RPG. 봇과 웹(`/rpg`)에서 같은 캐릭터로 한다.

- `!RPG` — 장비 강화, 스탯, 자동 전투, 친선전
- 특수 던전: `!RPG 일일`(매일 바뀌는 10층), `!RPG 로그라이크`(층마다 강화 고르기), `!RPG 보스러시`(회복 없이 보스 연속). 주간 순위가 있다.
- 진행 중인 전투는 DB에 저장돼서 봇을 재시작해도 이어진다.

### 🎲 TRPG (`TRPG.py`)
사이버펑크 2020 룰 엔진. 사람이 GM(진행자)을 맡고 봇은 룰 계산을 해 준다. 웹(`/trpg`)에서도 할 수 있다.

- `!TRPG 생성` · `시트` · `라이프패스` — 캐릭터 만들기(역할·능력치·스킬)
- `!TRPG 판정` · `공격` · `이니시` · `피해` · `회복` — 주사위 판정과 전투
- `!TRPG NPC추가` · `넷생성` — GM이 적 NPC와 넷러닝 시스템을 만든다
- `!TRPG 상점` · `구매` · `장착` — 장비

### ⛏️ 마인크래프트 연동
- `!마크` — 서버 상태와 접속자
- `!마크정보 [닉네임/@유저]` — 플레이어 정보 (JAS 모드 API)
- `!마크연동 [닉네임]` — 디스코드 계정과 마크 닉 연결
- `!서버켜기` · `!서버끄기` — 화이트리스트 유저가 서버를 켜고, 관리자가 끈다
- `!명령실행`(관리자) — RCON으로 서버 명령

### 🛠️ 관리자
- 돈 지급·압류, 경고(누적되면 타임아웃), 킥·밴, 채널 설정, 시세 조정, 종목·채굴기 추가·제거, 시스템별 점검 모드(`!시스템`)
- 관리자 명령은 봇 DM에서도 쓸 수 있다.

## 웹 — 우리거래소 (`web/`)
FastAPI로 만든 웹사이트. 디스코드 계정으로 로그인한다.

- **거래소**: 실시간 시세, 캔들 차트, 매수·매도, 지정가 주문, 레버리지, ETF 구성 종목, 실적 일정, 세금
- **RPG**와 **TRPG** 페이지

봇과 **같은 `bot.db`와 `tools.py`를 쓴다.** 그래서 웹에서 한 거래와 디스코드에서 한 거래가 똑같은 규칙을 따른다. 설치 방법은 [`web/README.md`](web/README.md).

## 파일 구조
```
우리봇v2.py        봇 본체 (명령어, 음악방송, 마크 연동, 서버 감시, 허세 상점 …)
tools.py           AI 함수 호출 툴 + 봇·웹이 같이 쓰는 경제 로직 (돈, 매매, 대출, 세금)
주식.py            주식 전부: 주가 엔진 / ETF / 캔들 차트 / 레버리지 / 배당·예약 주문
RPG.py             무한 던전 RPG 엔진 (봇·웹·AI 공용)
TRPG.py            사이버펑크 2020 TRPG 엔진
시장자료.json       주가 엔진이 쓰는 실제 시장 통계
시장자료_수집.py     시장자료.json 을 다시 만드는 스크립트 (네이버 금융 3년치)
web/server.py      우리거래소 웹 서버 (FastAPI)
web/static/        웹 화면 (index · rpg · trpg)
```

## 설치와 실행

### 필요한 것
- Python 3.13
- ffmpeg (음악방송)
- [deno](https://deno.com) (yt-dlp가 유튜브를 받을 때 씀)
- 디스코드 봇 토큰, Gemini API 키
- (선택) 마인크래프트 서버 RCON, JAS 모드 API

### 봇
```bash
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env      # 값 채우기
venv/bin/python 우리봇v2.py
```
처음 켜면 `bot.db`(SQLite)를 만들고 필요한 표를 알아서 만든다.

### 웹
```bash
cp web/.env.example web/.env      # 값 채우기
venv/bin/pip install -r web/requirements.txt
```
자세한 설정(디스코드 OAuth, nginx)은 [`web/README.md`](web/README.md).

### pm2로 계속 켜 두기
```bash
pm2 start venv/bin/python --name bot -- -u 우리봇v2.py
cd web && pm2 start "../venv/bin/uvicorn server:app --host 127.0.0.1 --port 8000 --proxy-headers" --name web
```
`주식.py`나 `RPG.py`를 고치면 `bot`과 `web`을 둘 다 재시작해야 한다 (둘이 같은 코드를 불러 쓴다).

## 환경 변수

### `.env` (봇)
| 키 | 설명 |
|---|---|
| `DISCORD_TOKEN` | 디스코드 봇 토큰 |
| `GEMINI_API_KEY` | AI 채팅용 Gemini API 키 |
| `PIXIV_REFRESH_TOKEN` | 이 저장소에선 안 씀 (픽시브 기능 빠짐) |
| `RCON_PASSWORD` | 마크 서버 RCON 비밀번호 |
| `MC_HOST` · `MC_RCON_PORT` | 마크 서버 주소와 RCON 포트 |
| `MCDASH_PASSWORD` | 마크 대시보드 비밀번호 (대시보드는 이 저장소에 없음) |

### `web/.env` (웹)
| 키 | 설명 |
|---|---|
| `DISCORD_CLIENT_ID` · `DISCORD_CLIENT_SECRET` | 디스코드 OAuth2 앱 정보 |
| `DISCORD_REDIRECT_URI` | 로그인 후 돌아올 주소 (`…/callback`) |
| `SESSION_SECRET` | 로그인 세션 암호화 키 (`python3 -c "import secrets; print(secrets.token_hex(32))"`) |
| `BOT_DIR` | 봇 폴더 경로 (`bot.db`·`tools.py`가 있는 곳) |
| `HTTPS_ONLY` | HTTPS로만 쓸 때 `true` |
| `BASE_PATH` | 하위 경로에 올릴 때 (예: `/stock`) |

비밀값은 전부 `.env`에서 읽는다. 코드에 적지 않는다.

코드 안의 디스코드 ID(채널·역할·서버·유저)는 공개용 가짜 번호(`1000000000000000xx`)다. 자기 서버에서 쓰려면 실제 ID로 바꿔야 한다. 관리자·부관리자 역할은 `우리봇v2.py`의 `관리자`·`부관리자`, 알림 채널은 `주가알림채널`·`대출알림채널`·`복권알림채널`.

## 알아 둘 것
- 봇과 웹은 다른 프로세스지만 같은 `bot.db`(SQLite, WAL)를 쓴다. 돈처럼 동시에 바뀔 수 있는 값은 SQL 안에서 `x = x + ?`로 바꾸고, 잔고 차감은 `WHERE money >= ?` 조건으로 해서 `rowcount`를 확인한다.
- 현금은 `_돈()`(봇) / `tools.돈변경()`(툴·웹)으로만 바꾼다.
- 디스코드 메시지는 2000자, 임베드는 칸 1024자·전체 6000자까지라 넘으면 나눠 보낸다.
- 주가 엔진의 세기는 `주식.py` 맨 위 설정값(`변동성_배율`, `가격제한폭`, `VI_기준` 등)으로 조절한다.
